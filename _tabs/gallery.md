## 📷 我的相册

这里是我的照片集合，记录生活中的美好瞬间。

### 🌟 精选照片

> 你可以在这里添加你的照片。将图片上传到 `assets/img/gallery/` 文件夹，然后使用下面的格式引用：

```markdown
![照片描述](/assets/img/gallery/photo1.jpg)
_照片说明_
```

### 📸 使用方法

1. 在 `assets/img/` 目录下创建 `gallery` 文件夹
2. 上传你的照片到该文件夹
3. 在这个页面用 Markdown 语法引用图片
