## 🎨 可用的主题配色

博客现在支持 6 套不同风格的配色方案，每套主题都支持浅色和深色模式。

### 主题列表

1. **默认主题** - Chirpy 原生配色
2. **暖阳主题** (`theme-warm`) - 橙色/粉色系，温馨舒适
3. **海洋主题** (`theme-ocean`) - 蓝色系，清爽专业
4. **森林主题** (`theme-forest`) - 绿色系，自然清新
5. **紫罗兰主题** (`theme-violet`) - 紫色系，优雅神秘
6. **樱花主题** (`theme-cherry`) - 粉色系，浪漫温柔
7. **极夜主题** (`theme-midnight`) - 深蓝/黑色系，高对比度

## 🔧 如何切换主题

### 方法一：修改配置文件（推荐）

编辑 `_config.yml` 文件，找到或添加以下配置：

```yaml
# 在文件末尾添加
body_class: theme-ocean  # 可选值：theme-warm, theme-ocean, theme-forest, theme-violet, theme-cherry, theme-midnight
```

然后提交并推送到 GitHub，等待部署完成。

### 方法二：直接修改 HTML

如果你想临时测试某个主题，可以在浏览器开发者工具中修改 `<body>` 标签的 class：

```html
<!-- 默认 -->
<body>

<!-- 暖阳主题 -->
<body class="theme-warm">

<!-- 海洋主题 -->
<body class="theme-ocean">
```

## 🌓 深色模式

所有主题都支持深色模式，点击页面右下角的主题切换按钮即可切换。博客会自动记住你的选择。

## 📸 主题预览

### 暖阳主题
- 主色调：橙红色 (#ff6b6b)
- 适合：生活博客、美食博客
- 风格：温暖、活力

### 海洋主题
- 主色调：蓝色 (#0984e3)
- 适合：技术博客、商务博客
- 风格：专业、清爽

### 森林主题
- 主色调：绿色 (#00b894)
- 适合：环保、自然主题
- 风格：清新、舒适

### 紫罗兰主题
- 主色调：紫色 (#6c5ce7)
- 适合：设计、艺术博客
- 风格：优雅、神秘

### 樱花主题
- 主色调：粉色 (#fd79a8)
- 适合：个人日记、摄影博客
- 风格：浪漫、温柔

### 极夜主题
- 主色调：深蓝/青色 (#00cec9)
- 适合：极简主义、科技博客
- 风格：现代、高对比

## 💡 自定义提示

如果你想创建自己的配色方案，可以编辑 `assets/css/custom.scss` 文件，参考现有主题的格式添加新的配色。

主要需要定义的变量：
- `--link-color`: 链接颜色
- `--link-hover-color`: 链接悬停颜色
- `--heading-color`: 标题颜色
- `--btn-primary-bg`: 按钮背景色
- `--btn-primary-hover-bg`: 按钮悬停背景色

## 🎯 推荐搭配

- **技术博客**：海洋主题 + 深色模式
- **生活博客**：暖阳主题 + 浅色模式
- **摄影博客**：樱花主题 + 浅色模式
- **极简风格**：极夜主题 + 深色模式

随时可以根据心情和内容切换主题，让博客更有个性！
