# 你好，世界！

这是我的第一篇博客文章。今天我成功搭建了自己的 GitHub Pages 博客！

## 关于这个博客

我会在这里分享：

- 📚 学习笔记
- 💻 技术文章
- 🌟 生活感悟
- 🎯 个人项目

## 如何发布新文章

发布新文章很简单：

1. 在 `_posts` 文件夹中创建新文件
2. 文件名格式：`YYYY-MM-DD-标题.md`
3. 添加文章头部信息（Front Matter）
4. 用 Markdown 写内容
5. 推送到 GitHub

就这么简单！
